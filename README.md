# siedmiodniowe-cele
Weekly goals organizer (grid) with heatmap based overdue tracking (Flask/Python project)

## Features
- Basic Goal managment (CRUD) on daily grid
- Goal overdue heatmap (gets "hotter" when older) - optional
- Adding reoccuring goals
- adding weekly goals (for each week)
- Goals achieved marked as completed tasks on todo list (also visible in daily/grid)
- Sing-In/Sign-Up along wit Logout functionality included

## Tech stack:
- Python
- Flask
